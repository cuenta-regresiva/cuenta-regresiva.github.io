Cuenta Regresiva Personalizable

Nueva versión de Cuenta Regresiva.

Objetivo

Permitir que cada usuario configure su propio evento, fecha y hora, conservando el diseño futurista de la aplicación original.

Reglas del proyecto

- No modificar la versión productiva mientras se desarrolla esta versión.
- No incluir fechas privadas como valores predeterminados.
- Guardar la configuración de cada usuario en su propio dispositivo.
- Preparar la aplicación para su posterior empaquetado como APK.
